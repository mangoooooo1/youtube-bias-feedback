# ViewLens 확장 프로그램 설치 가이드 (테스트용)

YouTube 시청 패턴을 분석해 피드백을 주는 **ViewLens** 확장 프로그램을 설치하는 방법입니다.
Chrome 웹 스토어 심사 전 테스트용으로, **개발자 모드**로 직접 설치합니다. 순서대로 따라 하시면 됩니다.

> 준비물: **Chrome 브라우저**, 전달받은 **zip 파일**(`viewlens-v1.0.0.zip`), 전달받은 **참여 코드**

---

## 1단계 — 압축 풀기
1. 받은 `viewlens-v1.0.0.zip` 파일을 바탕화면 등 찾기 쉬운 곳에 저장합니다.
2. 파일을 **마우스 오른쪽 클릭 → "압축 풀기"(또는 "여기에 압축 풀기")** 합니다.
3. 생긴 폴더를 열었을 때 **`manifest.json`** 파일이 보이면 정상입니다.
   - ⚠️ 이 폴더 위치를 기억해 두세요 (4단계에서 선택합니다).

## 2단계 — 확장 프로그램 관리 페이지 열기
1. Chrome 주소창에 아래를 입력하고 Enter:
   ```
   chrome://extensions
   ```
   (또는 오른쪽 위 점 3개 메뉴 → 확장 프로그램 → 확장 프로그램 관리)

## 3단계 — 개발자 모드 켜기
1. 화면 **오른쪽 위의 "개발자 모드"** 스위치를 **켭니다(ON)**.

## 4단계 — 확장 프로그램 불러오기
1. 왼쪽 위에 나타난 **"압축해제된 확장 프로그램을 로드합니다"** 버튼을 클릭합니다.
2. 1단계에서 압축을 푼 **폴더를 선택**합니다.
   - ⚠️ `manifest.json` 파일이 **직접 들어 있는 폴더**를 선택해야 합니다 (그 위 상위 폴더 ❌).
3. 목록에 **ViewLens** 가 나타나면 설치 성공입니다.

## 5단계 — 시작하기 (참여 코드 입력)
1. 브라우저 오른쪽 위 **퍼즐 조각 아이콘**을 클릭하고, **ViewLens 옆 핀(📌)** 을 눌러 툴바에 고정합니다.
2. 툴바의 **ViewLens 아이콘**을 클릭해 팝업을 엽니다.
3. **전달받은 참여 코드**를 입력하고 시작합니다.

## 6단계 — 사용하기
1. YouTube에서 **평소처럼 영상을 시청**합니다.
2. ViewLens 아이콘을 클릭하면 **오늘의 시청 분석과 피드백**을 볼 수 있습니다.
   - 참고: 시청 분석/피드백은 **10분간 시청이 없을 때 자동으로 생성**됩니다. 영상을 본 직후에는 "수집 중"으로 보일 수 있어요.

---

## 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| "매니페스트 파일이 없거나 읽을 수 없습니다" 오류 | 폴더를 잘못 선택한 경우입니다. `manifest.json`이 **직접 들어 있는 폴더**를 다시 선택하세요. |
| 툴바에 아이콘이 안 보임 | 오른쪽 위 **퍼즐 조각 아이콘** 클릭 → ViewLens **핀(📌) 고정**. |
| "개발자 모드 확장 프로그램을 사용 중지" 경고 | 개발자 모드 설치 시 뜨는 **정상 안내**입니다. 무시하고 사용하시면 됩니다. |
| 새 버전을 받았을 때 | `chrome://extensions`에서 ViewLens의 **새로고침(↻)** 버튼을 누르거나, 제거 후 새 폴더로 다시 설치하세요. |

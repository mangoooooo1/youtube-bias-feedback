```
youtube-bias-feedback/

│   ├── content.js                # Content Script — YouTube 페이지에서 영상 ID/제목 감지

│   ├── pipeline/                 # 분석 파이프라인 모듈 (background.js가 import)
│   │   ├── youtube.js            # YouTube Data API v3 — 카테고리 조회
│   │   ├── categories.js         # 카테고리명 → VL 키 매핑
│   │   ├── analysis.js           # Shannon Entropy 계산 및 분포 집계
│   │   └── llm.js                # Gemini 2.5 Flash API — 자연어 피드백 생성
│   │
│   ├── popup/                    # 팝업 UI (360×600 px)
│   │   ├── popup.html            # 팝업 진입 HTML — vl-popup-root 마운트 후 viewlens-popup.js 로드

│   │   ├── viewlens-data.js      # VL 전역 객체 — 카테고리, 엔트로피 헬퍼, 목 데이터, GROUPS/TONES 정의
│   │   ├── viewlens-logo.js      # markSVG(), wordmarkHTML() SVG 헬퍼
│   │   ├── viewlens-ui.js        # vlBadge() 등 재사용 UI 컴포넌트
│   │   ├── viewlens-screens.js   # 화면별 HTML 생성 함수 (온보딩, 오늘, 주차별, 대조군, 설문)
│   │   ├── viewlens-app.js       # ViewLensPopup 클래스 (상태 관리·렌더) + Studio 클래스
│   │   └── viewlens-popup.js     # 실제 팝업 전용 — RealPopup, boot(), chrome.storage 연동
│   │
│   ├── studio/                   # 브라우저 기반 UI 미리보기 도구 (개발용)
│   │   ├── ViewLens.html         # 브라우저에서 직접 열어 팝업 UI를 확인하는 HTML
│   │   ├── tweaks-panel.js       # TweaksPanel 클래스 — 그룹/다크모드/시점 등 실시간 조작
│   │   └── tweaks-panel.css      # 트윅스 패널 스타일
│   │
│   └── assets/                   # 정적 리소스
│       ├── fonts/                # Pretendard woff2 (400·500·600·700·800)
│       ├── icons/                # 확장 아이콘 (16·32·48·128 px)
│       ├── viewlens-logo.png     # 로고 이미지
│       └── viewlens-mark.png     # 마크(심볼) 이미지
│
├── server/                       # Node.js 백엔드 (Express + better-sqlite3)
│   ├── app.js                    # Express 앱 설정 및 라우터 마운트
│   ├── db.js                     # SQLite 연결 및 테이블 초기화
│   ├── .env.example              # 환경변수 템플릿
│   ├── youtube_bias.db           # SQLite DB 파일 (gitignore)
│   ├── middleware/
│   │   └── responseHandler.js    # 공통 응답 포맷 미들웨어
│   └── routes/
│       ├── participants.js       # POST /api/participants — 참여자 등록
│       ├── sessions.js           # POST /api/sessions — 세션 데이터 저장
│       ├── surveys.js            # POST /api/surveys — 설문 응답 저장
│       └── video-events.js       # POST /api/video-events — 개별 영상 이벤트 저장
│
├── package.json                  # 루트 워크스페이스 설정 (pnpm)
├── pnpm-workspace.yaml           # pnpm 모노레포 워크스페이스 선언
└── README.md                     # 프로젝트 소개 및 설치 가이드
```

## 주요 데이터 흐름

```
YouTube 페이지
  └─ content.js (영상 감지)
        └─ background.js (세션 관리)
              ├─ pipeline/youtube.js   (카테고리 조회)
              ├─ pipeline/analysis.js  (엔트로피 계산)
              └─ pipeline/llm.js       (Gemini 피드백)
                    └─ storage.js (chrome.storage.local에 저장)
                          └─ popup/viewlens-popup.js (UI 렌더)
```

## 그룹 코드

| 코드 | 설명 | feedback 화면 |
|---|---|---|
| `EXP` | 실험군 | O (엔트로피 + 피드백) |
| `CON` | 대조군 | X (단순 시청 현황) |
| `TEST-EXP` | 연구자 — 실험군 UI 확인용 | O |
| `TEST-CON` | 연구자 — 대조군 UI 확인용 | X |
